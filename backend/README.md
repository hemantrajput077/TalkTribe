# TalkTribe Backend

FastAPI backend for TalkTribe Language Exchange Platform.

## Features

- User authentication and registration
- PostgreSQL with async SQLAlchemy
- Redis for caching
- Alembic migrations
- JWT authentication

## Tech Stack

- FastAPI
- PostgreSQL + asyncpg
- Redis
- SQLAlchemy 2.0 (async)
- Alembic
- Pydantic
