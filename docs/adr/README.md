# TalkTribe Architecture Decision Records

This folder contains the Architecture Decision Records (ADRs) for TalkTribe.

Each ADR records:

- Context
- Decision
- Alternatives considered
- Consequences
- Status

Current ADRs:

1. ADR-001 — Modular Monolith
2. ADR-002 — Domain-Oriented Backend Structure
3. ADR-003 — PostgreSQL as Primary Durable Store
4. ADR-004 — Redis for Realtime / Presence / PubSub
5. ADR-005 — WebSocket for Realtime Transport
6. ADR-006 — WebRTC for Voice Calls
7. ADR-007 — Backend Signaling with Peer-to-Peer Media
8. ADR-008 — Application-Level Transaction Ownership
9. ADR-009 — Cross-Domain Communication Through Contracts
10. ADR-010 — JWT + Refresh Token Authentication
11. ADR-011 — Admin as an MVP Role
12. ADR-012 — Rule-Based Matching for MVP
13. ADR-013 — One-Week Message Retention
14. ADR-014 — Notifications Deferred Until After Peer-to-Peer Connection

These ADRs should be updated only by adding a new ADR that supersedes an old decision, rather than silently rewriting architectural history.
